# 四视图输入分析

输入为用户提供的 1254×1254 心脏外观插图，四个区域的文字仅用于识别视角。前面、左侧面、后面、右侧面分别裁切，未进行生成式图像编辑。统一画布便于对照，不能视为已解算相机。

观察：非对称、连续卵锥形心室；尖端在正面向图像右下偏移。前方两心耳遮住大血管根部；后方宽厚心房覆盖上半部。红色弓形血管顶部有三个开放分支；前方蓝色弯管跨到解剖左方；上下蓝色腔静脉在解剖右侧。后面两侧各两条红色短管。侧面显示前后厚度及心房后方凸起。

宏观层：连续心室外壳、后方心房、右心房、两个心耳、大血管系统。中观层：房室沟、前后室间沟、冠脉及静脉、血管壁和凹入管腔。微观层：分叶心耳、脂肪小叶、肌表面沟纹、血管壁细纹、逐级变细冠脉。

材质观察：肌肉为暖红色，中等粗糙度、非金属、局部湿润高光；心耳更淡；大血管红/蓝饱和色；脂肪黄橙色、颗粒状。PBR 数值为外观估计，旧参考裁片可作为组织微纹理种子，但不能冒充新参考提取。

左右约定：+Z 前方，+Y 上方，+X 解剖左侧。left 相机必须位于 +X，right 相机位于 -X。前后不能各造一个模型。

多视图约束：front 约束主干位置和尖端偏移；rear 约束宽厚心房、四个短管和横向房室沟；left/right 约束深度、长轴和遮挡次序。四视图中细小血管不能逐根可靠对应；相机俯仰及缩放并未标定，微血管与内部联系仍为推断。

重试计划：保留单图基线；先同机位捕获基线；在结构修正中更新轮廓站点、后房体积及大血管三维路径；随后增加后壁脂肪沟与分支；最后检查四向渲染、点选、分解、移动端及性能。目标是四向连贯的可旋转近似，不声明医学准确或自动网格恢复。
