# 心脏模型知识性检查

原始独立解剖检查对象：`output/anatomy-06/` 对应的源码和同一模型的前、后、左、右及斜视图。范围为正常成人心脏外部解剖，冠脉采用右冠优势教学示例。

**材质优化后复查：** 当前版本为 `output/material-final/`。解剖布局、冠脉源码、心室外壳位置/面片索引及语义部件清单保持一致；大血管和心房/心耳仅提高原曲面的采样密度。最终实际网格再次通过36项结构、108组血管间距和12项交互检查。七类连续微纹理只影响外观，不表示新增的组织学结构；当前没有图片位移贴图。结果与局限见 [surface-review.md](surface-review.md)。下文独立医学知识复核的对象仍明确为原始 `anatomy-06`，本轮不将自动回归或材质复核称为新的医学专家审查。

本报告检查模型是否表达了正确的外部归属、走行和连接关系，不将插图相似度或程序运行成功当作生物学准确率。

## 本轮纠正

| 问题 | 最终处理与依据 |
|---|---|
| 心室只有未区分的整体外壳 | 划分左右心室外表面，左室形成心尖，右室占前面主要投影面积。心耳保留对应房体的基底连接。[OpenStax 心脏解剖](https://openstax.org/books/anatomy-and-physiology/pages/19-1-heart-anatomy) |
| 肺动脉左右支的分叉不明确 | 两支使用肺动脉干同一个分叉点；右支位于升主动脉及上腔静脉后方，并消除与上腔静脉的管壁交叠。主动脉弓三支按头臂干、左颈总、左锁骨下排列。[NCBI 大血管解剖](https://www.ncbi.nlm.nih.gov/books/NBK547680/) |
| 冠状动脉绕行和下行分支混淆 | 左主干分出前室间支和回旋支；回旋支、右冠沿房室沟，前/后室间支沿对应室间沟。右冠发出后室间支，且母干不会在分支前骤然变细。回旋支终止于左后侧房室沟。[OpenStax 心脏解剖](https://openstax.org/books/anatomy-and-physiology/pages/19-1-heart-anatomy) |
| 缺少主要心静脉汇流关系 | 加入后房室沟冠状窦及其向右房的外部连接；心大静脉上行后转入左房室沟，心中静脉在十字部附近汇入，心小静脉沿右侧回流。[NCBI 心静脉解剖](https://www.ncbi.nlm.nih.gov/books/NBK549786/) |
| 曲线穿壳、动静脉共线，造成断管或错误连通外观 | 对贴面路径密集采样；房室沟内动静脉分为相邻路线；调整局部转弯并检查实际管壁间距。此项为模型自身的几何证据。 |

另外核对了四条肺静脉在左房后方的外部根部、上下腔静脉在右房的外部根部，以及肺干在主动脉根部前方的关系。这里的“连接”只指可见外形和几何嵌入。[NCBI 大血管解剖](https://www.ncbi.nlm.nih.gov/books/NBK547680/)

## 原始解剖修正版证据（anatomy-06）

- 结构检查 **36/36 通过**：读取实际网格和血管曲线，含固定的冠脉必需连接清单、心耳基底交叠、心室表面分区、前方主要冠脉贴面、右冠/后室间支管径过渡。
- 血管分离检查 **108/108 对通过**：72对非相连大血管，加36对冠状动脉与心静脉。每轴501点，半径取实际渲染顶点环；使用额外采样余量。最小净距分别为0.07918和0.01938，单位为模型局部单位，并非毫米。
- 四向截图和斜视图来自同一模型，捕获报告绑定本地与实际服务源码的 SHA-256；检查报告另记录自身脚本与捕获报告哈希。
- 浏览器交互 **12/12 通过**，包含实际点选、分解/恢复和手机布局；无已记录的运行时错误。TypeScript检查与Vite构建通过，保留现有大于500 kB的bundle提示；未配置ESLint。

## 仍属简化或未验证的内容

- **外部形态简化**：房室体块、心耳轮廓、沟的宽深、管径、细支数量和纹理。纹理不表示真实细胞尺度。右冠优势只是本模型选用的一种常见解剖形式。
- **没有建模**：四个真实腔室、瓣膜、隔膜、主动脉窦内的冠脉开口、贯通管腔和血流。左右心室是一个封闭外壳的两组面片，不能据此验证内部流出道分别连到哪个腔室。
- **检查的边界**：间距算法是有采样余量的外部检查，不是全部三角面精确无自交证明；未覆盖冠脉同类血管之间、冠脉与所有其他组织之间的全部碰撞。血管短截口的凹孔仅供展示。
- **原图吻合**：旧候选仍未通过完整四视图图像门槛。其历史分数不属于本次解剖修正版，也没有改写为通过。

**独立知识复核结论：有限范围通过。** 对最终四视图、实际几何报告及源码哈希进行独立复核后，未发现新的明确外部解剖错接；本轮发现的错误已修正。该结论只覆盖本报告所列的正常成人、右冠优势外部示意，不构成医学专家认证或临床用途验证。
