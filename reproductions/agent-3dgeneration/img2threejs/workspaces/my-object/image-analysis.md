# 线粒体剖视参考图分析

## 输入与适用性

- 参考图：`../test/屏幕截图 2026-08-26 011321.png`
- 图像尺寸：200 × 278 px，白色背景，单一目标，完整轮廓可见。
- 适用性结论：`conditional-pass`。适合生成教育展示用、程序化、风格化 Three.js 模型；不适合从单图声称解剖级或制造级精确。
- 目标用途：实时浏览器交互式教学模型，支持点击部件与爆炸视图。

## 1. 识别与分类

- 观察：一个线粒体风格的细胞器剖视模型，外部为封闭豆形壳体，观察侧存在一块大面积剖切窗口。
- 分类：`organelle cutaway model`；`primaryDomain: object`；有机、分层壳体、内部曲面褶皱。
- 识别置信度：0.97。

## 2. 整体形态与轮廓

- 整体包围体接近沿 Y 轴竖直的弯曲椭球/豆形体；高度约为宽度的 1.6–1.8 倍，厚度由单视图推断约为宽度的 0.65–0.8。
- 轮廓近似双侧但并非严格对称：上端较圆，右侧外弧连续，左侧中下部因剖切窗口和下端鼓包形成不规则凹凸。
- 外壳表面连续、圆钝，没有硬折线；所有主曲面都应采用有机连续拓扑而非 cuboid 拼接。

## 3. Macro → meso → micro 分解

- Macro：外壳主体、剖切窗口内的基质体、内膜/嵴系统。
- Meso：切口边缘环、内膜外周边界、连续蛇形嵴褶皱、下部环状褶皱、基质内颗粒群。
- Micro：外壳凹凸纹理、切口边缘高光带、内膜暗金色边线、基质细斑点、分散小球状颗粒、褶皱局部厚度变化。

## 4. 空间与连接关系

- `<cutaway-rim, embedded-in, outer-shell>`：剖切边缘与壳体前侧重叠并形成厚度可见的环形切口。
- `<matrix-volume, inside, outer-shell>`：基质位于壳体内部，略低于切口边缘前表面。
- `<inner-boundary, attached-to, matrix-volume>`：金色内膜沿剖切区域内缘连续分布。
- `<cristae-network, attached-to, inner-boundary>`：多个蛇形折叠从内周边界向基质内部伸入，视觉上应连续连接而不是漂浮线段。
- `<matrix-granules, embedded-in, matrix-volume>`：颗粒位于褶皱间隙，略凸出于基质表面。

## 5. 材质与表面（PBR）

- 外壳：非金属、暖棕色、中等粗糙度；存在低幅随机位移/法线变化与暗色凹点。
- 切口边缘与内膜：非金属金黄色，satin/gloss 响应，粗糙度低于外壳；边缘有窄高光。
- 基质：浅米黄色、较高粗糙度、低对比细斑点。
- 颗粒：浅褐到暗褐色，半哑光，小球/扁球几何。

## 6. 色彩与 finish

- 外壳：深棕阴影 → 中棕主体 → 暖橙棕受光面。
- 内膜：暗赭金边线 → 饱和金黄主体 → 浅黄高光。
- 基质：低饱和米黄，局部暖灰阴影。
- finish：外壳为粗糙有机表面；内膜为较平滑的蜡质/脂质风格表面；基质为细颗粒 matte。

## 7. 身份定义特征

1. 竖直豆形外轮廓与右侧连续大弧。
2. 前侧大面积不规则剖切窗口及明显厚边缘。
3. 金黄色内膜沿窗口内缘形成连续边界。
4. 五组左右交错、蛇形回转的嵴褶皱，而不是平行直板。
5. 下部环状/涡旋式内膜褶皱。
6. 基质内分散颗粒与细斑点。
7. 外壳粗糙棕色表面与内膜光滑金黄表面的强材质对比。

## 8. 单图不确定性

- 隐藏：背面、剖切窗口真实深度、外壳与内膜在背面的连续方式。
- 不确定：嵴褶皱数量和每条折叠的真实三维厚度；参考图可能是教学插画而非严格结构图。
- 推断：使用前侧浅剖切 relief，而不是对壳体做完全布尔切除；背面保持圆钝豆形。
- 需要更多视图时：只有在要求解剖级准确或完整环绕内部结构时才需要 front/side/back；本任务按可运行的风格化教学模型继续。

## 初始质量契约摘要

- 轮廓、剖切窗口、连续内膜边界、交错嵴褶皱、下部涡旋和材质对比必须从主视角清晰可读。
- 至少 3 个 macro、5 个 meso、8 个 micro/detail 组；至少 2 个重复系统（褶皱、颗粒/斑点）。
- 必须检查 front、left/right 斜视、rear 四个方位；不得出现漂浮褶皱、穿出外壳、切口遮挡内部或背面敞口。
