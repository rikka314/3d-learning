# 项目复现

这里按需存放 3D AI 项目的复现工作。每个项目使用独立子目录；同一研究主题可先建立主题目录，再在主题目录下拆分具体项目。

建议每个复现目录至少包含一个 `README.md`，说明：

- 原项目、论文和代码仓库链接
- 复现目标与完成标准
- 环境、依赖和硬件要求
- 数据准备与运行命令
- 当前进度、结果和已知问题

目录示例：

```text
reproductions/
└── 主题名称/
    └── project-name/
        ├── README.md
        ├── upstream/
        └── outputs/
```
