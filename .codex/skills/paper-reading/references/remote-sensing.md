# 遥感论文专项证据检查

仅在论文涉及卫星、航空、无人机、SAR、LiDAR、高光谱、多光谱或其他遥感数据时加载本文件。

## 1. 空间泄漏与样本独立性

检查训练、验证和测试样本是否来自相邻或重叠空间区域。随机 patch 划分可能使相邻纹理、同一地物或同一原始大图同时进入训练集和测试集，导致结果偏高。

至少确认：

- 划分单位是像素、patch、场景、地块、城市还是区域；
- patch 是否重叠，以及重叠发生在划分之前还是之后；
- 同一原始影像切出的样本是否跨集合；
- 是否采用 spatially disjoint、region-wise、scene-wise 或 cross-location 划分；
- 增强后的近重复样本是否跨集合。

## 2. 多模态配准与信息公平性

对光学、SAR、LiDAR、HSI、MSI、DSM 等多模态输入检查：

- 空间分辨率、覆盖范围和时间是否一致；
- 重采样、裁剪、投影转换和配准误差如何处理；
- 不同方法是否获得完全相同的模态、波段和辅助数据；
- 缺失模态、云遮挡、噪声和时间差异是否被真实模拟；
- 预训练模型是否使用了额外遥感数据或标签信息。

## 3. 标签与类别分布

检查标签来源、层级和噪声：

- 单标签、多标签、像素级或对象级标注是否与指标匹配；
- 类别是否长尾，是否报告 macro 与 micro 指标；
- 多标签任务是否报告 mAP、F1、precision/recall 或 per-class 结果；
- 类别层级、共现关系和未知类是否被合理处理；
- 标签是否由地理数据库自动映射，可能存在时间错位或边界噪声。

## 4. 泛化证据

“泛化更强”至少应由下列一种真实变化支撑：

- 跨区域或跨城市；
- 跨季节或跨时间；
- 跨传感器或跨平台；
- 跨分辨率；
- 跨数据集；
- 域适应或域泛化设置。

同一区域随机划分上的性能提升不能单独证明地理泛化。

## 5. 指标与定性结果

检查指标是否适合任务和类别不平衡。遥感可视化还应确认：

- 热力图、注意力图或分类图是否来自测试区域；
- 可视化是否只挑选成功案例；
- 边界、碎片化和小目标表现是否有定量证据；
- OA 很高时，AA、Kappa、macro-F1 或 per-class 指标是否揭示少数类问题。

## 6. 复现风险

重点记录：

- 数据下载版本、地理范围与许可；
- 投影坐标、裁剪窗口和配准流程；
- patch 大小、步长、重叠率和划分脚本；
- 波段选择、归一化和无效值处理；
- 随机种子、多次运行统计和硬件；
- 预训练权重、外部数据和空间增强策略。
