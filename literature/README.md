# 文献与资料

这里统一保存与 3D AI 有关的论文、文章、课程、数据集、工具和项目链接。

## 目录

| 目录 | 用途 |
|---|---|
| `papers/` | 论文、技术报告及补充材料 |
| `report/` | 多文献专题调研、综述及其下载清单 |
| `courses/` | 课程、讲义和学习路线 |
| `tools/` | 工具、平台和相关使用资料 |

需要进一步分类时，可以在这些目录中按主题建立子目录，例如 `generation/`、`reconstruction/`、`representation/`。

## 收录建议

- 尽量保留原始标题、作者、年份和来源链接。
- 本地保存的文件使用容易识别的名称，避免 `paper1.pdf` 一类命名。
- 较长的阅读理解可以单独写到 `thoughts/`，再从索引表链接过去。
