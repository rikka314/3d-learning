# 医学三维模型：分叉、心耳与局部过渡的论文及开源方法

研究日期：2026-09-08。范围：现有 Blender MCP 与 img2threejs 参数化心脏模型的几何优化，重点是教育展示。本文是研究与实验建议，没有安装、运行或验证所列项目在当前资产上的效果，也没有修改模型。

## 1. 结论与适用边界

最值得优先尝试的组合是：**血管采用中心线驱动的专用分叉连接区；心耳采用带根部、颈部、弯曲与尖端的形状描述；最后对连接区做受约束的局部平滑。**

三个问题对应不同层次：

| 现象 | 需要检查什么 | 主要方法 |
|---|---|---|
| 分叉处像几根管子插在一起 | 是否只是重叠？分叉腹部和分流尖端是否建模？ | 专用 junction patch，或局部隐式融合 |
| 心耳像独立球块 | 是否仍以椭球作为主体？根部是否突然收缩？ | 解剖模板或沿轴变化的截面模型，再连接心房 |
| 局部有折痕或鼓包 | 边界是否接上？两侧切线和曲率是否协调？ | 连接拓扑修复后进行边界受约束的 fairing |

Mesh 是结果的表达形式，不决定产生它的方法。中心线放样、隐式场等值面提取、模板变形都可以产生 Mesh，却具有不同的形状控制能力。Three.js 能生成几何，Blender 也包含渲染；更换软件本身不会自动补上解剖形状先验。

“平滑”也有三种容易混淆的含义：平滑法线主要改变光照；移动网格顶点改变几何；建立共享连接面改变拓扑。只做第一种不会消除穿插，只做第二种通常不会把两个独立部件接成一张表面。

## 3. 血管分叉：优先研究的三条路线

### 3.1 专门建立三开口连接区：vascularmd

**Decroocq 等，2023，Modeling and hexahedral meshing of cerebral arterial networks from centerlines，Medical Image Analysis 89:102912。**

论文和作者代码把血管网络作为带半径的中心线图处理，并对分叉单独建模。重要思路是把一进两出的连接区当作一个整体，控制端部截面、分流位置与尖端圆滑程度，再接回各段血管。它避免把分叉完全交给几根圆管的相交结果。[论文](https://arxiv.org/abs/2201.08279)、[作者代码 vascularmd](https://github.com/megdec/vascularmd)

对当前项目的工程建议：保留现有路径生成，截取分叉附近的一小段，替换成专用 junction patch。只取表面网格并三角化即可用于 GLB，不必复制 CFD 所需的六面体体网格流程。

适配难点：输入中心线图和半径需要清理；复杂非共面多分叉有局限；脑动脉上的证据不能直接当作肺动脉或整个心脏的解剖准确性证明。代码存在并不代表当前参数可直接运行。仓库为 GPL-3.0。

更早的医学依据是 **Ghaffari 等，2017，Large-scale subject-specific cerebral arterial tree modeling using automated parametric mesh generation for blood flow simulation**。其分叉参数化涉及 Bézier 控制和过渡连续性。适合学习为什么需要控制连接处的方向，而不能只调管径；本次未确认作者提供可直接使用的实现。[论文](https://pubmed.ncbi.nlm.nih.gov/29126049/)

其 2018 年验证工作还提示：除外观以外，应检查血管直径、中心线和表面距离。作者数据上的误差不能照搬为当前教育模型的验收阈值。[验证论文](https://pubmed.ncbi.nlm.nih.gov/30048917/)

### 3.2 中心线变成隐式场，再提取统一表面：VMTK

可以把这条路线想象成沿中心线放置半径可变的小球，让这些球形成一个连续体积，再提取体积外壳。VMTK 的 `vtkvmtkPolyBallLine` 与 `vmtkcenterlinemodeller` 提供对应的中心线场构造能力；输出标量图像后，还需要等值面提取。[类文档](https://www.vmtk.org/doc/html/classvtkvmtkPolyBallLine.html)、[脚本实现](https://github.com/vmtk/vmtk/blob/master/vmtkScripts/vmtkcenterlinemodeller.py)、[项目](https://github.com/vmtk/vmtk)

它适合快速做“几根相交管段变成共同外表面”的基线。这里的隐式场可以是传统数学函数，不需要神经网络，也不必严格等同于真实 signed distance。

限制尤其关键：球包络或布尔并集不自动保证切线连续；交汇区可能鼓包、变窄；分辨率过低会丢小血管；空间相近但不该相连的血管可能被误融合。建议只在指定连接区生成，固定出口截面，并使用允许连接的部件名单。VMTK 仓库采用 BSD 许可。

相关论文包括 **Zhou 等，2016，Implicit Tubular Surface Generation Guided by Centerline**，以及 **Qi 等，2020，Skeleton Marching-based Parallel Vascular Geometry Reconstruction Using Implicit Functions**。后者涉及影像和局部数据拟合，并不是仅输入几条任意中心线就能完整照搬的算法；本次未确认两者有可直接采用的作者代码。[Zhou 论文](https://arxiv.org/abs/1606.03014)、[Qi 论文](https://link.springer.com/article/10.1007/s11633-019-1189-4)

OpenVDB 是另一种工程基础设施：可表示稀疏体素场、进行 CSG 和滤波，但 `csgUnion` 本身不是保证光滑的融合算子。它更适合需要定制局部场运算时采用，不能视为医学形状算法。[代码示例](https://www.openvdb.org/documentation/doxygen/codeExamples.html)、[滤波接口](https://www.openvdb.org/documentation/doxygen/LevelSetFilter_8h.html)

### 3.3 放样、并集与指定连接面的局部 blend：SimVascular

SimVascular 的医学血管建模流程值得参考：沿路径建立截面，放样得到管段，再组合并处理连接区。局部 blend 的思想是指定需要过渡的面及范围，而不是让全模型一起变圆。[建模文档](https://simvascular.github.io/documentation/modeling.html)、[用户手册](https://simtk.org/docman/view.php/187/779/SimVascular_UserManual.pdf)、[源码](https://github.com/SimVascular/SimVascular)

对现有 Blender 流程，最可借鉴的是“有选择地融合并约束半径”。具体支持的操作取决于模型类型和几何内核，不能据此承诺任意 GLB 导入后都可以一键圆角。

另有 **svMorph**：公开代码用于已有血管表面与中心线上的局部形变，适合参考如何限定影响区域；其狭窄、动脉瘤或支架相关功能不等同于分叉融合。[2023 年论文](https://pubmed.ncbi.nlm.nih.gov/36282508/)、[MIT 许可代码](https://github.com/SimVascular/svMorph)

## 4. 心耳：首先改变形状先验

一个球体无论如何增加细分和光滑，仍然受到球形描述的限制。下一版应显式表达根部边界、颈部、延伸方向、沿途截面变化、弯折和尖端；有需要时增加叶状分支。左心耳与右心耳应分别处理。

### 4.1 直接相关的论文：左心耳 SDF 与统计形状模型

**Juhl 等，2024，Signed Distance Field based Segmentation and Statistical Shape Modelling of the Left Atrial Appendage** 是本次最贴近心耳问题的来源。它研究从 CT 得到左心耳形状，并通过配准、颈部处理及尖端/边界地标建立统计形状模型。它提供的是医学形状学习路线，不能简单解释成给一个球体加 SDF 平滑。[论文与方法全文](https://arxiv.org/html/2402.07708v1)

作者已公开 [LAAmeshing_and_SSM](https://github.com/kristineaajuhl/LAAmeshing_and_SSM)，包含分割和配准相关代码及权重链接。但 README 仍有占位内容，并注明部分形状模型分析代码待发布；本次未确认明确的许可证，也未下载验证权重。应称为“作者公开研究代码”，不能承诺完整即用或默认允许任意再分发。

当前可借鉴的部分是：把根部与尖端作为明确约束，把形状变化与连接处理分开。若只有外观参考图，建议先做可解释的弯曲截面模型，再用解剖参考校正；若获得合适模板或 CT，才推进完整配准/统计模型路线。这是项目适配推论。

### 4.2 形状模板与解剖地标：bi-atrial SSM、AugmentA、ShapeWorks

**Nagel 等，2021，A bi-atrial statistical shape model for large-scale in silico studies of human atria: Model development and application to ECG simulations** 提供双心房统计形状研究，配套数据包含均值形状和变化模式。可用于理解“在真实解剖变化范围内调形状”，但数据许可与表面定义仍需单独核查。[论文](https://pubmed.ncbi.nlm.nih.gov/34450467/)、[配套数据](https://zenodo.org/records/5004620)

**AugmentA，2023** 是患者特异性心房模型生成工具。可借鉴解剖地标、模板配准及语义保留；其真实输入与后续生理建模需求显著多于当前外观模型。仓库采用 Academic Public License，包含非商业教学研究限制，不能按 MIT/BSD 处理。[论文](https://doi.org/10.1016/j.compmedimag.2023.102265)、[代码](https://github.com/KIT-IBT/AugmentA)、[许可证](https://raw.githubusercontent.com/KIT-IBT/AugmentA/master/LICENSE.md)

**ShapeWorks** 是可复用的统计形状工具，能从一组形状建立对应关系与变化模型，适合以后构建心耳模板库。它需要一组样本或已有先验模型，不会从一张示意图自动得到可信的医学形状分布。工具代码采用 MIT；输入数据许可另算。[流程](https://sciinstitute.github.io/ShapeWorks/latest/getting-started/workflow.html)、[代码](https://github.com/SCIInstitute/ShapeWorks)

**表面类型必须对齐：CT 分割得到的血池/心内膜表面，不等于当前展示所需的心外膜外表面。** 把内腔模板直接贴到外形模型上，可能产生位置、厚度或连接语义错误。医学来源提高参考价值，不自动解决这项转换。

## 5. 局部过渡：约束比更多平滑次数更重要

连接通常需要先保证位置接上，再使两侧方向协调，最后控制弯曲变化。G0、G1、G2 分别描述位置、切线方向和曲率层面的几何连续性；离散三角网格通常是对目标光滑曲面的近似。

### 可复用工具

| 方法 | 能解决什么 | 不解决什么 |
|---|---|---|
| CGAL `fair` | 以边界约束对选定顶点做双拉普拉斯 fairing | 不会自动把两个独立 Mesh 连接；可能因约束不足求解失败 |
| libigl biharmonic deformation | 用平滑位移场分配局部编辑，保持边界或控制点 | 不自带解剖知识，也不保证拓扑改变正确 |
| VTK windowed-sinc / PyVista `smooth_taubin` | 改善已有网格噪声，减轻普通平滑收缩问题 | 不保证直径、体积精确守恒，也不自动修复穿插 |

[CGAL 6.1 fairing 文档](https://doc.cgal.org/6.1/Polygon_mesh_processing/group__PMP__meshing__grp.html)、[libigl 双调和变形教程](https://libigl.github.io/tutorial/#biharmonic-deformation)、[VTK 算法文档](https://vtk.org/doc/nightly/html/classvtkWindowedSincPolyDataFilter.html)、[PyVista 接口](https://docs.pyvista.org/api/core/_autosummary/pyvista.polydatafilters.smooth_taubin)

推荐操作顺序：确定应连接的部件 → 去除或替换相交连接区 → 建立共同表面 → 冻结远端和截面边界 → 优化过渡顶点 → 检查管径、鼓包和碰撞。普通单孔 hole filling 不能直接当作三开口血管分叉算法。

经典 **Taubin 1995，Curve and Surface Smoothing without Shrinkage** 解释了为什么要避免普通反复平均带来的收缩；VTK windowed-sinc 属于相关的滤波式平滑路线，不能把其实现简单说成完全相同的两步算法。[论文](https://graphics.stanford.edu/courses/cs468-01-fall/Papers/taubin-smoothing.pdf)

一般几何理论中，**Gourmel 等，2013，A gradient-based implicit blend** 专门讨论隐式融合中的鼓包、远距离意外融合等问题，适合解释为什么简单 smooth union 仍不够自然。本次没有确认可直接采用的作者代码，也没有将其视为医学验证结果。[作者机构记录](https://researchportal.bath.ac.uk/en/publications/a-gradient-based-implicit-blend)

## 6. 最小对照实验建议

以下为后续实验设计，尚未执行。不要一开始重建全心脏。

### 实验 A：同一个 Y 型血管分叉

保留同一组中心线、出口截面和半径，比较三种构造：当前独立管段；局部隐式融合加受约束平滑；vascularmd 思路的专用连接区。

评估：

1. 使用统一灰色材质、灯光和相机，检查多个角度与分叉近景，避免贴图掩盖几何。
2. 检查是否仍有内部相交面、非流形边、自交和意外连接。允许开放的端口需预先定义，不能把所有边界一律视为错误。
3. 比较端部直径、分叉角、连接区截面，以及修改范围之外的顶点位移。
4. 检查小血管是否被吞掉、相邻独立血管是否被误并。

### 实验 B：一个心耳与对应心房

先确认左/右侧及展示表面。保持根部与关键地标，比较现有椭球和“颈部—弯曲轴—变化截面—尖端”模型，再用同一种连接算法接回心房。这样可以分清改善来自形状先验还是接缝处理。

重点看根部宽度、颈部到主体的变化、方向与尖端形态，以及是否仍显得像外加球块。没有医学标注真值时，可以报告参考一致性与几何质量，不应声称患者级解剖精度。

### 实验 C：过渡优化消融

在同一张已连接的网格上比较：仅平滑法线、普通局部平滑、固定边界的 fairing。绘制或检查线框与曲率变化，并同时检查尺寸漂移。

验收阈值应根据教育展示目标和坐标尺度另行制定。现有模型如没有校准物理尺度，不使用毫米级医学误差作为验收标准。

## 7. 实施优先级与交付风险

第一优先级：保留现有中心线/语义结构，为一个 Y 分叉实现显式连接区；同步将一个心耳从椭球改为更丰富的参数形状。

第二优先级：增加局部 fairing，限制修改范围、管径漂移及错误融合。以局部隐式路线作为速度较快的对照，验证是否已足够。

第三优先级：获得表面类型匹配、许可明确的解剖模板，做地标驱动配准；有样本数据后再考虑 SSM，而不是先训练新网络。

对当前展示型资产，离线 Python/Blender 生成几何、导出 GLB、Three.js 展示是一种方便的工程安排；它是对本项目的建议，不是论文结论。如果要求浏览器内实时调分叉参数，可以将显式连接区算法实现为 TypeScript。

重建拓扑会影响 UV、材质分区、顶点索引和标签绑定。应从新版本导出并重新映射、验证，不能拿旧截图或旧校验结果证明新资产正确。外形连成一体也不代表内部管腔已经贯通；需要内腔时必须另行建模和验证。

## 8. 阅读顺序与证据说明

建议顺序：

1. vascularmd README、论文分叉图及 `Nfurcation.py`：理解为什么需要“分叉零件”。
2. Juhl 2024 左心耳论文与代码目录：理解颈部、尖端、配准和形状变化。
3. CGAL fair 与 libigl biharmonic deformation：理解固定边界的局部修改。
4. VMTK centreline modelling：建立隐式路线对照。
5. AugmentA、ShapeWorks：在有合适数据后推进模板和统计形状。

检索覆盖血管连接、心耳/心房形状、通用几何过渡三条分支，优先核对作者论文、官方文档和仓库。重点阅读了分叉建模、左心耳配准方法和局部平滑接口，而非只按摘要推荐。经典算法与较新医学工作并列，以输入适配性优先于发表时间。

可信度：所列方法及仓库存在性有直接来源；对当前几何输入的适配判断来自源码结构与算法要求；实际改善程度、运行成本和参数范围尚待上述对照实验验证。没有将“公开代码”“完整可复现”“开源许可允许集成”混为一谈。
