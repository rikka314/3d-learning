# 3D AI Learning

这是一个面向 3D AI 的长期学习与研究工作区，用来集中保存文献资料、个人思考，以及按需开展的项目复现。

## 目录

| 目录 | 用途 |
|---|---|
| `literature/` | 收集资料并维护阅读索引，下面分为 `papers/`、`report/`、`courses/`、`tools/` |
| `thoughts/` | 记录个人思考、问题、方向判断和阶段性总结 |
| `reproductions/` | 存放项目复现；每个复现项目单独创建一个子目录 |
| `.codex/skills/` | 保存当前项目使用的 Codex 研究工作流 |

## 使用方式

1. 收到新资料时，先登记到 `literature/README.md`，本地文件也放在 `literature/` 中。
2. 阅读后的理解、疑问和想法写入 `thoughts/`，文件名建议使用 `YYYY-MM-DD-topic.md`。
3. 决定复现某个项目时，在 `reproductions/` 下新建独立子目录，并在该目录保留来源、环境和运行步骤。
4. 需要检索最新进展时，优先使用 `.codex/skills/` 中的 `research-ops`、`exa-search` 和 `deep-research`。

当前不预设具体技术栈；每个复现项目可以独立选择环境和依赖。
